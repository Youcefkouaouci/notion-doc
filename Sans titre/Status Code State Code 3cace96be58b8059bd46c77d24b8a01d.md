# Status Code // State Code

### 🔨 Sensors/Trackers

**100** → Libre

**200** → Associé

### 🔨 Materials/Zones

**100** → Non connecté

**200** → Connecté

**601** → Immobile

**602** → Perdu

**603** → Retrouvé

### 🔨 Inventories/Messages

**100** → Non traité

**150** → En cours de traitement

**200** → Traité

**201** → ignoré

**401** → Tracker non trouvé

**402** → Tracker non associé

**403** → Trame dupliquée

**404** → Date invalide

**500** → Erreur

### ⚙ Conformity

**200** → Conforme

**400** → A Contrôler

**401** → En Quarantaine
